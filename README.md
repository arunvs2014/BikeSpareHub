# 🚴 BikeSpareHub

BikeSpareHub is a Spring Boot based web application that allows users to browse, purchase, and manage bike spare parts online.

---

## 📌 Project Description

This application provides an online platform for managing bike spare parts inventory and handling customer purchases. It includes user authentication, cart management, and transaction processing features.

---

## ✨ Features

- 🔐 User Registration & Login
- 🛒 Add to Cart Functionality
- 💳 Secure Transaction Page
- 📦 Product Management
- 👨‍💼 Admin Panel
- 🗄 Database Integration

---

## 🛠 Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven
